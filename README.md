# Mert Erdem Elmacı | Kişisel Web Sitesi

Kendimi, eğitim ve deneyimlerimi, teknik yetkinliklerimi ve kariyer hedeflerimi paylaşmak için hazırladığım kişisel web sitesi.

🌐 **Canlı Site:** https://mertthebabo.github.io

## Hakkında

Eskişehir Teknik Üniversitesi Bilgisayar Programcılığı mezunuyum.

Yazılım geliştirme, sistem ve ağ teknolojileri, bulut teknolojileri ve yapay zekâ alanlarında kendimi geliştirmeye devam ediyorum.

Bu siteyi hem kendimi tanıtmak hem de eğitim, deneyim ve kariyer yolculuğumu tek bir yerde toplamak amacıyla oluşturdum.

## Sitede Neler Var?

- Hakkımda ve kariyer hedeflerim
- Projelerim
- İş ve staj deneyimlerim, eğitim bilgilerim
- Teknik yetkinliklerim, sertifikalarım ve dillerim
- İndirilebilir özgeçmiş (PDF)
- İletişim formu, GitHub ve LinkedIn bağlantılarım
- Koyu/açık tema, klavye ve ekran okuyucu desteği

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages

## Geliştirme

Siteyi zaman içinde yeni projelerim, deneyimlerim ve öğrendiğim teknolojilerle güncellemeye devam edeceğim.

Sitenin bazı iyileştirmelerinde yapay zekâ destekli bir kodlama aracından (Claude Code) yararlandım; içerik ve kararlar bana ait.
